# English Tutor

English-learning games for a 9-year-old Hungarian child.

| Folder | What |
|---|---|
| [`demo/`](demo/) | **Nóra angol kalandja** – the current working app: a local Python server plus a vanilla JS frontend, also deployable as a static GitHub Pages site. See [`demo/README.md`](demo/README.md) for features, the dictionary format and how to run it. |

Quick start: double-click `demo/start.bat`, or run `py demo/server.py`.
